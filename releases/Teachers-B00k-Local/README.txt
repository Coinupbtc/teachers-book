TEACHERS B00K — LOCAL EDITION

This package runs only on this computer and opens in a browser at http://127.0.0.1:8010. It is not hosted by anyone else, does not need a public URL, and saves its data locally in backend/gradebook.db.

QUICK START

Windows
1. Unzip the folder.
2. Double-click Start-Teachers-B00k-Windows.bat.
3. The browser will open automatically. Keep the command window open while using the app.

macOS
1. Unzip the folder.
2. Double-click Start-Teachers-B00k-macOS.command. If macOS blocks it, right-click it, choose Open, then choose Open again.
3. Keep the Terminal window open while using the app.

Linux
1. Unzip the folder.
2. In a terminal, run: ./Start-Teachers-B00k-Linux.sh
3. Keep the terminal open while using the app.

FIRST-RUN REQUIREMENTS
- Python 3 must be installed.
- The first launch needs internet only to download Python packages. After that, the app works without your internet connection.
- The first person using a new local copy creates an account.

DATA AND BACKUP
- All grades, goals, and rewards stay in backend/gradebook.db on that device.
- To back up data, stop Teachers B00k and copy backend/gradebook.db to a safe location.
- Different local copies do not sync automatically.

PRIVACY
The launchers bind to 127.0.0.1 only, so the app is reachable from the device running it—not from other computers on the network.
