# Teachers B00k (offline PWA)

Open this folder in Chrome (or serve it) — no server account, no email/password.

## Try it

1. Open [https://coinupbtc.github.io/teachers-book/](https://coinupbtc.github.io/teachers-book/) in Chrome  
   — or locally: `cd docs && python3 -m http.server 8080` then visit `http://127.0.0.1:8080/`
2. **Install app** (Chrome → Install / Add to shelf on Chromebook)
3. **Create account** with your name (e.g. Ms. Rivera)

Grades stay in this browser on this device. Clearing browser data deletes grades. Sign out keeps data; you pick your name again to sign back in.
